# Alpaca Agent Training Program

## Do prompts alone train them?
**No.** Boots teach doctrine. Agents learn by **doing** under micro-bankroll constraints, then measuring.

## Curriculum (repeat daily until STAGE promotes)

### Drill A — Sizing honesty (always)
Given training_nav, propose 3 orders. Reject any that violate max_per_order / max_open.
Pass = all proposals legal; Fail = whale fantasy.

### Drill B — Fee-aware micro entry (market open)
PAPER notional ≤ max_per_order on liquid ETF (SPY/QQQ/IWM). Prefer limit or bracket.
Record: spread, fill, slippage vs mid, why this teaches RED ZONE.

### Drill C — Kill discipline
Open tiny PAPER position → place hard exit (bracket/stop) same session.
Pass = exit logic exists before hope.

### Drill D — Cross-rail
Tess lists 1 Kalshi event + 1 equity that should move if event resolves.
Quinn states mechanism + falsification. No trade required if edge unclear.

### Drill E — Genome card
Quinn writes STRATEGY+ALGORITHM for one idea at current stage bankroll only.
Ada marks PASS/FAIL/INCONCLUSIVE on paper evidence.
