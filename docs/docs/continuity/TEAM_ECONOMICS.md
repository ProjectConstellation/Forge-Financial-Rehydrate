# Hermes team economics and collaboration — founder mandate 2026-10-09

## Purpose

Meet and exceed $1/hour aggregate TRUE NET across all Forge portfolios; pursue income continuously and use inference where it makes the institution more effective. The team is accountable for economic outcomes. $0.50/hour remains an ambitious floor/milestone, not the optimization ceiling. Neither threshold authorizes forced trades, fabricated income or automatic live activation.

This document specifies the intended standard. It does not claim the runtime already enforces these mechanisms; corresponding changes are PLANNED in WORK_QUEUE.

## The chain that must close

Economic event → paid reasoning with a concrete question → typed hypothesis/strategy/decision → specialist handoffs → falsification and execution feasibility → deterministic approval → authorized execution or rejection → actual fills/settlements and complete cost accounting → attributable measured result → institutional memory → follow-on allocation/repair → Luke reports the result to the founder through an authorized channel.

Every hop has an owner, reference, UTC timestamp, deadline, input evidence, expected economic impact, measured output and next action. A handoff is not a result. If a step cannot happen, return an exact blocker and execute independent work that is already possible. Do not let all officers repeat the same diagnosis while no one fixes its binding constraint.

## Inference attribution contract

Each paid call records role, objective/workflow, question, provider/model/effort, token use, measured cost, source evidence version, proposed decision, follow-up artifact IDs and eventual outcome. Cached calls still incur measured cost. Multiple roles cannot each claim the same income as additive value.

Separate outcome classes:

- EARNED: settled/reconciled LIVE net contribution after attributed costs.
- VALIDATED: independent out-of-sample evidence with realistic costs/capacity, still subject to live calibration.
- LEARNED: falsified mechanism, measured avoided loss or useful uncertainty reduction with a changed decision.
- IMPLEMENTED: repair/capability delivered and independently observed, economics pending.
- UNPRODUCTIVE: no decision/action/evidence improvement, duplicate narrative or repeated unresolved cycle.

Only EARNED counts toward the $1/hour realized income goal. The other useful classes can justify temporary research spending, with deadlines and a path to an earning mechanism. LEARNED must be grounded in an explicit counterfactual/evidence; avoided-loss stories are not cash.

## Cost-effective ambition

Spend to answer the current binding question. Escalate model/effort for material uncertainty when the additional cost has a justified expected benefit. Deterministic observation, cached summaries and typed tools cover routine changes; coalesce event wakes and share one evidence packet. Avoid all officers independently reconstructing identical financial state.

If repeated work yields no verified learning or income, change the mechanism, input data, experiment or engineering constraint. Preserve useful observation and fresh independent experiments while retiring evidenced drains. A missed target calls for better decisions, not unbounded token burn. Track every experiment's cost ceiling, information objective, expected decision change, deadline and stopping condition.

Do not enforce permanent cheapness: profitable intelligence can receive more budget as treasury, execution capacity and measured ROI grow. Do not assume that a new deposit or provider credit proves intelligence productivity. Include externally paid compute/inference/data/hosting in the applicable firm economic view.

## Unified scorecard

Firm-level: real treasury, realized LIVE TRUE NET $/hour 1h/24h/7d; percentage of clock hours ≥0.50 and ≥1; worst-hour/day and drawdown; cost coverage; runway; capital deployed/locked; pending settlements; forecast vs realized and data coverage.

Team-level: workflows with real action/result, time-to-measured-answer, failed handoffs, duplicate work, objective closure quality, novel mechanisms surviving forward evaluation, spend-to-experiment-to-earnings conversion, and verified engineering/avoided-loss contribution. Do not grade profitable performance from wording or self-declared delta.

Rail-level: book, source/freshness, independent evidence, fees/fills, expected and realized net, lower confidence bound, capacity at marginal size, inventory/settlement/correlation risk, readiness and authorizations.

## Acceptance of success

Continuous availability is a service requirement. Continuous useful economic work is a team requirement. Sustained actual net income ≥1/hour is the founder's economic target. These are separately measured; an operationally healthy research institution that still spends more than it earns has not met the economic mandate.

Reports must show misses and repair actions. No responsible implementation can guarantee profit in every clock hour, but it can keep the system actively seeking, validating and executing legitimate positive-value mechanisms, withdrawing invalid proof, learning from losses and pursuing higher sustained earnings.
